# makefun-u-xvader-tell-a-whole-story-in-32-characters-f86dd978

One Wi-Fi network name, 32 characters or fewer, that tells a whole story:
**TheWiFiOutlivedOurMarriage**.

The marriage is over. The divorce is done, the house is split, the
arguments are finished — and the one thing still standing, still broadcasting
every evening at full bars, is the Wi-Fi. The name is the whole settlement in
six words: two people, one failed marriage, and a router that outlasted them
both.

## How it runs

```sh
python3 main.py
```

Writes the single name to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`). Stdlib only, no network, no randomness: the same name
every run.
